# NosHen logo

The mark is an n and a u hooked together: buyer and seller, two equal halves of one deal. The green half is the buyer and the teal half is the seller. How to use it: [`NosHen-logo-guidelines.md`](NosHen-logo-guidelines.md).

| File | Use |
| --- | --- |
| `noshen-mark.svg`, `noshen-mark-1024.png`, `noshen-mark-512.png` | The mark in white on a green tile: profile pictures, app icons, hackathon project logo |
| `noshen-logo.png`, `noshen-logo.svg` | Mark + name, for light backgrounds (transparent) |
| `noshen-logo-white.png` | Mark + name in white, for green backgrounds or photos (transparent) |
| `noshen-logo-on-dark.png` | Mark + name on NosHen's deep background, ready to drop in |
| `svg/` | Every master: horizontal, stacked, symbol and wordmark, in colour, reversed, white, black and green, plus the small-size symbol (`noshen-symbol-small.svg`) for 16–23 px |

Colours: NosHen Green `#0F6E56`, NosHen Teal `#14B8A6`, Ink `#17201D`, deep background `#062A22`.

The name is drawn as outlines, not set in a font, so every file renders the same everywhere. Never retype "NosHen" to recreate it.

In the apps, the logo is the `Wordmark` component in `packages/ui/src/ui.tsx`. The favicon, app icons and notification badge are in `apps/web/public` and `apps/admin/public`.
