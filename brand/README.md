# NosHen logo

| File | Use |
| --- | --- |
| `noshen-mark.svg`, `noshen-mark-1024.png`, `noshen-mark-512.png` | The mark on its own: profile pictures, app icons, hackathon project logo |
| `noshen-logo.png`, `noshen-logo.svg` | Mark + name, for light backgrounds (transparent) |
| `noshen-logo-white.png` | Mark + name, for dark backgrounds or photos (transparent) |
| `noshen-logo-on-dark.png` | Mark + name on NosHen's deep teal, ready to drop in |

Colours: deep teal `#0F6E56`, bright turquoise `#14B8A6`, deep background `#062A22`. The name is set in Sora Bold.
`noshen-logo.svg` loads Sora from Google Fonts; where it can't (some design tools), use the PNGs.

The shield is the "shield-check" icon from Tabler Icons (MIT licence), the same icon set the app uses.
